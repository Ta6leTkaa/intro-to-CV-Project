# Live demo photographs

Source: Ultralytics Construction-PPE, November 2026 revision.
https://docs.ultralytics.com/datasets/detect/construction-ppe/

Licensed under Creative Commons Attribution 4.0 International; see LICENSE.txt.
Three validation photographs were EXIF-transposed, converted to RGB, resized with
aspect ratio preserved to at most 1600 px, and saved as JPEG (quality 92).
`source.json` records the original archive members, original file hashes, resulting
file hashes, archive hash and download URL. These are live inference examples,
separate from the historical frozen test images and labels used by the project.
